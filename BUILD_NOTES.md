# Build and verification notes

The source project has been implemented and its automated tests pass in the build environment.

## Verified here
- PyTorch 2.10 CPU forward pass and loss computation

- Causal generation path
- Byte-BPE encode/decode round-trip
- Checkpoint save/load and sample generation
- `pytest -q`: 2 tests passed

## Included demo checkpoint
`checkpoints/best.pt` is a small CPU smoke-training checkpoint (116,352 parameters) created from a short Shakespeare excerpt for validating the complete train → checkpoint → generate path. It is **not** the final full-corpus training run, and its text quality is intentionally treated as a pipeline smoke test. `SAMPLE_GENERATION.txt` is generated by that checkpoint.

## Full requested training
Run `python prepare.py` to download the complete Tiny Shakespeare corpus (about 1.1 MB), train a fresh BPE tokenizer, and encode the official corpus. Then run `python train.py` for the default 5,000-step training run. The best full-corpus checkpoint will replace `checkpoints/best.pt`. On CPU, training may take a long time; a CUDA/MPS device is recommended for faster experiments.
